## 📖 Sobre o Repositório

Este repositório reúne uma coleção de **scripts em Luau** para **Roblox Studio** e executores, otimizados para funcionar tanto em **dispositivos móveis** como em **PC**, com destaque para o **Delta Executor**. Inclui utilitários de hacking retro, veículos terrestres, aquáticos e aéreos, além de ferramentas auxiliares de iluminação e radar.

---

## 📂 Lista de Scripts

| 📄 Ficheiro | 📝 Descrição |
|---|---|
| `Flipper_Zero.lua` | GUI virtual retro de hacking com módulos **Sub-GHz**, **RFID** e **IR** |
| `GrabPack.lua` | Mãos interativas dos **Capítulos 1, 2, 3** e **Protótipos** |
| `Helicoptero_AH6.lua` | **AH-6 Little Bird** com cockpit, dials de **RPM/altitude**, radar e **miniguns** |
| `Barco.lua` | Veículo aquático tático |
| `Submarino.lua` | Exploração subaquática |
| `Avião.lua` | Aeronave de asas fixas |
| `Carros.lua` | Controlo de veículos terrestres |
| `LanternaRadarHorror.lua` | Lanterna dinâmica e radar de terror |
| `Luz.lua` | Módulo auxiliar de iluminação |
| `RADAR.lua` | Módulo auxiliar de radar |
